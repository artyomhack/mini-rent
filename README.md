# Mini-rent - приложение для сдачи и аренды вещей

## Основные сценарии:

**Объекты для аренды:**
1. Пользователь может создать объявление о сдаче объекта в аренду.
2. Пользователь может арендовать объект по опубликованному объявлению.
3. Пользователь может снять объявление об объекте в аренду

**Пользователи:**
1. Пользователь,  который зарегистрирован, может создать объявление
2. Пользователь,  который зарегистрирован, может бронировать объект в аренду по объявлению.
3. Пользователь, который зарегистрирован, может отмечать место для аренды на карте.

**Бронь:**
1. При создании брони, важно получать на выбор только актуальные свободные брони.
2. Бронь имеет мин ед. времени равную один час.
   (Пример: 12.00 - 13.00)
3. Бронь имеет макс. ед. времени в зависимости от бизнес требования.
   (Пример: 2 д - 48 часов) По умолчанию: 1 день.
4. Бронь не может быть создана больше максимального времени, которое задаёт сам бизнес
   (Пример: макс. время 2 дня, бронь создаётся на 3 дня).
5. Бронь не может быть создана меньше чем минимальное время
   (Пример: мин. время 1 час, бронь создаётся на 15 минут).
6. Бронь имеет промежуток по времени равную ед. времени в один час.
   (Пример: 12.00 - 14.00 = 2 часа, каждый промежуток один час)
7. Бронь не может быть создана на один и тот же объект аренды, если есть смежные брони. (Для этого важно учитывать 1 пункт, но текущий является строгим правилом, если не удалось по какой-то из тех. причин соблюсти 1 пункт.)
